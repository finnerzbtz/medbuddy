# iPhone fixes — 10 September 2026

Implemented locally in the existing working tree. The previous Release A changes, default sadness calculation, medication schedules, dose records, stock, reminders and self-care separation remain intact. No schema or cloud changes, purchase activation, deployment or TestFlight upload were made.

## Findings and changes

- **Settings switches:** the global accessibility checkbox rule reduced each switch to 22 × 22 pixels while its 18-pixel pseudo-element still travelled 15 pixels. Switches now retain a 52 × 32 track and a fully contained knob, rendered without replaced-input pseudo-elements. Labels remain the larger tap targets; checked state, keyboard operation, reduced motion and forced-colour native rendering are retained.
- **Zen garden:** the general native modal maximum height incorrectly shortened this full-screen game, exposing app navigation underneath. Full-screen room games now own their full viewport height and safe-area padding. The tray reserves room for controls, both canvases share the same bounds through rotation, short screens can scroll to all controls, and Safari touch-opened routine activities retain their return-focus target. Existing sand, rake, sound and room assets are reused.
- **Audio:** music/effects switches now actually enable audio and show their effective state while the master is muted. Web Audio requests the playback session when the user enables sound, resumes on the next interaction after interruption, and does not unmute merely because the user touches the app. Sand audio resumes its own context during the initiating gesture instead of an asynchronous React effect. Voice, music, record-player and sand output were measured through real Web Audio analysers in both tested engines.
- **Reminders:** the reported physical-device delivery failure was **not reproduced** in the simulator: the original and updated app both delivered a real local notification after leaving the app. The installed Capacitor plugin can resolve `schedule()` before iOS's asynchronous `UNUserNotificationCenter.add` completes, so the app now verifies the pending OS queue, including bounded retries for that race, before reporting success. Failure is visible, verified scheduling replaces the estimated scheduled-through display, foreground presentation is explicit, and the test waits 10 seconds so the phone can be locked. New native diagnostics read banner, sound and lock-screen settings and provide a direct action to open Reminduh's iPhone notification settings. Medication reminders remain local scheduled notifications, not server-originated APNs pushes.

The playback-session choice follows the [WebKit report and iOS 17 guidance](https://bugs.webkit.org/show_bug.cgi?id=237322). The notification queue uses the installed Capacitor implementation and its [local notifications API](https://github.com/ionic-team/capacitor-local-notifications/blob/main/README.md).
