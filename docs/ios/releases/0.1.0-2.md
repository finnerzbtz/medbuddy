# Reminduh 0.1.0 (2) — internal TestFlight beta

Prepared 10 September 2026 for the existing Reminduh Beta group. Same bundle ID
`com.reminduh.app`, team `37N43RUU8P`, App Store Connect app `6809836995`.
The source tag is `ios/0.1.0-2`. This is not a public App Store submission.

## What to test

- Update over build 1 without uninstalling; export a backup before testing. Check
  medication schedules, dose records, supply and settings survive the update.
- First-time setup now offers notification permission. Existing users can enable
  reminders in My Blobby → Reminders and send a test notification. Close/lock the
  app to check delivery; tap the notification to open Today's check-ins.
- Turn on music/effects, listen to Blobby, lock/unlock the phone and test headphones,
  silent mode and an interruption. Audio is optional and mute is preserved.
- Rake the sensory sand garden in portrait and landscape. Check the full canvas,
  controls and screen edges. Check settings switches and larger text.
- Try optional quiet-break routines, Done / Not today / Later / Undo and Keep today
  small. Routine choices must not record medication or change medication supply.
- Try medication-name suggestions with a partial name and keyboard/touch selection.

## Scope and recovery

This bundle is offline: email accounts/cloud sync are disabled by empty build-time
endpoints. Source code for optional cloud sync is retained, but the production
Release A migration and real-email/native-auth validation remain pending. Purchases
and Apple Music are disabled. No backend migration or public deployment is included.

Schema 1 migrates to schema 2 with the original browser and native snapshots retained
before replacement. The data key stays the same. Export backups before device testing;
do not uninstall a personal-data installation. Keep this compatible beta installed
when accessing v2 data; an older app is not a supported storage downgrade.

## Verification and status

Local domain, migration and native planner checks passed. Notification onboarding
previously passed a fresh iOS 26.5 simulator test with the real Apple permission
prompt, notification delivery outside the app and persistence after relaunch.
The release run additionally covers TypeScript/offline packaging, asset contracts,
medication autocomplete, reminders, optional activities, WebKit/Chromium audio and
safe-area controls. See the repository workflow for repeatable gates.

Physical iPhone upgrade/storage, actual notification behaviour under Focus and
restarts, silent mode/headphones/audio interruptions, VoiceOver/Dynamic Type and
participant usability validation remain device checks. Automated checks do not
establish complete accessibility compliance.
